# License selection required before public release

This staging directory intentionally does not declare a license. The authors must
choose and add a project license before publishing the repository. Without a
license, recipients may inspect the code but do not automatically receive rights
to copy, modify, or redistribute it.

The original BADIT repository currently does not advertise a repository-level
license. Its code is therefore not bundled here. The PEFT copy from the research
workspace is also excluded; install a released `peft` package or add an explicitly
licensed dependency after the authors complete a compatibility review.

Recommended author action: confirm ownership of the new BADIT-TF implementation,
choose an OSI-approved license, add the full license text as `LICENSE`, and record
third-party notices in `NOTICE`.
